[ 01 ]

Démarrage rapide

Cloner, construire l'ISO, booter.

$ git clone https://github.com/loicjazon/ubuntu-freshinstall.git && cd ubuntu-freshinstall && make build-iso
  • Télécharge l'ISO officielle si absente
  • Mot de passe haché en SHA-512
  • Testable dans QEMU avant la clé USB

[ 02 ]

Comment ça marche ?

Trois étapes, enchaînées automatiquement.

  1. 01 /

    Autoinstall

    Un seed pilote l'installeur Ubuntu sans interaction : locale française, clavier AZERTY, LVM sur disque entier, réseau en DHCP, SSH.autoinstall/autoinstall.yaml
  2. 02 /

    Premier boot

    Un service systemd attend le réseau, clone ce dépôt puis lance le playbook en local. Il se désactive une fois terminé.first-boot/first-boot-provision.sh
  3. 03 /

    Playbook Ansible

    Paquets apt, .deb, snaps, applications en tarball, Docker, Oh My Zsh et dotfiles optionnels.ansible/site.yml

[ 04 ]

Prérequis

Une machine Linux pour construire, une machine cible pour installer.

Construire l'ISO

  • Une machine Linux ou une VM avec xorriso et wget.
  • Environ 10 Go d'espace disque (ISO source et ISO générée).
  • Optionnel : openssl et python3-yaml pour préremplir l'utilisateur.
  • Optionnel : qemu-system-x86 pour tester sans clé USB.

Machine cible

  • Un PC x86_64 capable de démarrer sur clé USB.
  • Une connexion réseau au premier boot, pour cloner le dépôt et installer les paquets.
  • Pour le chiffrement disque matériel (optionnel) : TPM 2.0 et Secure Boot.
